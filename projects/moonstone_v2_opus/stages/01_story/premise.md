# Premise

## Who it is for
Developers and operators running Claude Code sessions on more than one machine.

## The problem
Sessions are scattered across windows and machines, and cloud tools add latency and lock-in.

## What the product changes
Moonstone puts every Claude Code session across every machine in one local window, and the agents act (orders, shipments) instead of just talking.

## The one thing to remember
One window, your hardware, full control: this is Moonstone.
